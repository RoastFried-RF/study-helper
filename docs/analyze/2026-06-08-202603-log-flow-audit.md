## 2. 실재 결함 (calibrated 우선순위)

### 🔴 HIGH — 실사용 영향 확인

**H1. HTTP 5xx 미재시도 (가장 단단한 finding, 독립 2회 검증)**
- 위치: `src/downloader/video_downloader.py:491-496, 520-530`
- 근거: `_RETRYABLE = (IncompleteRead, ChunkedEncodingError, ConnectionError, Timeout)` — `requests.exceptions.HTTPError` 부재. `raise_for_status()` 가 5xx 에서 던지는 HTTPError 는 `except Exception: break` 로 즉시 중단.
- 영향: CDN 503/502 일시 장애 → 재시도 없이 영구 실패 전환. effect **M**.
- 수정: `_RETRYABLE += (requests.exceptions.HTTPError,)` 단, 4xx(401/403=쿠키 갱신 필요)는 status 분기로 즉시 중단 유지.
- confidence: **certain**

### 🟡 MEDIUM — 실재하나 영향 제한적

**M1. content.php XML 경로 stub 필터 비대칭**
- 위치: `src/downloader/video_downloader.py:261-262`
- 근거: 네트워크 경로(210/217)는 `_is_valid_mp4(url)`(exclude_patterns: intro/preloader/preview/thumbnail) 적용. content.php XML 파싱 경로(261)는 `if media_uri and captured["url"] is None:` 로 **필터 미적용**. XML media_uri 가 stub 을 가리키면 다운로드→검증실패→삭제→재시도 사이클 낭비.
- 수정: `if media_uri and _is_valid_mp4(media_uri) and captured["url"] is None:`
- confidence: certain (영구손실 아님 — 재시도되므로 낭비만)

**M2. driver-death 시 완료보고 무한 낭비 + 재시작 미트리거**
- 위치: `src/player/background_player.py:341-412` (`_report_completion`)
- 근거: "Connection closed"(driver dead) 예외를 catch 만 하고 driver-death 단축 없이 3회×2초 낭비 후 None 반환. `_is_browser_dead_exception` 체크/브라우저 재시작 트리거 없음. (단 상위 루프가 "재생 미완료" 로 감지하므로 거짓 완료 마킹은 아님.)
- 수정: 예외가 browser-dead 면 즉시 break + caller 에 신호(예외 타입/플래그) 전파 → 상위의 `_recover_if_browser_dead` 경로로 연결.
- confidence: certain (메커니즘) / 영향은 효율·복구지연

**M3. STT 빈 결과 14회 — silent fail + 모니터링 사각**
- 위치: `src/stt/transcriber.py:189-274, 267-273`
- 근거: 로그 14회 "STT 결과 비어 있음". mp4 직접입력/무음 시 빈 segment 반환·예외 없음. segment=0 을 `_log.warning` 으로만 → 모니터링 무시.
- 수정: 입력 형식 검증(mp3/wav만) + segment=0 시 `_log.error` 상향.
- confidence: certain (로그 14건 증거)

**M4. progress flush 배치 크래시 손실**
- 위치: `src/ui/auto.py` (`_SAVE_INTERVAL=5` 배치 flush)
- 근거: 5강의마다 flush. 배치 전 크래시 시 최대 4강의 진행 손실. except 가 KeyboardInterrupt 만, finally 강제 flush 없음.
- 수정: 사이클 말미 강제 `flush()` 또는 운영 시 `PROGRESS_SAVE_INTERVAL=1`.
- confidence: likely (실제 크래시 손실 증거는 없음 — 설계상 위험)

### 🟢 LOW — 경계/방어/운영성
